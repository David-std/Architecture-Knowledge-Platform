# v0.3.0 release evidence

Version 0.3.0 promotes the completed local-first Architecture Knowledge Platform product line after repository productization, branch normalization and final functional validation.

## Evidence retained for the release

- Durable ingest and causal outbox processing were exercised with retries, leasing, quarantine, recovery and reconciliation.
- Authorization and multi-vault isolation were exercised across lexical, semantic, graph, review and evidence boundaries.
- Governed Git publication, rollback, managed-Git backup/restore and recoverable publication failure windows were executed.
- Real multilingual semantic retrieval used a versioned local embedding provider and persisted embedding generations through the production retrieval path.
- Typed multi-hop graph retrieval, retrieval planning, ContextPackets and grounded compilation were exercised through maintained product paths.
- Document intelligence exercised the deterministic baseline, Docling and durable OCR paths; unavailable optional providers remain explicitly unproven rather than treated as passing.
- OpenTelemetry traces and metrics were exercised across supported local API, worker and operational flows.
- Maintained evaluation workflows cover semantic retrieval, document intelligence, concurrency, resilience, bounded scale and a real-model Agent A/B harness.
- Repository hygiene rejects generated benchmark JSON, personal workstation paths, phase-coded construction residue and temporary workflow artifacts.

## Interpretation

The release establishes the supported local-first product behavior and its explicitly bounded evidence. It does not claim hostile internet readiness, arbitrary-corpus retrieval superiority, production-scale throughput, universal document-provider quality or Agent A/B superiority where the executed evidence did not support those claims.

Detailed run artifacts remain in CI/release history rather than being versioned as generated report snapshots in the product tree.
