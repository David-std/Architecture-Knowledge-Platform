# Pre-P9 root-report archive

These files were first-class root reports during construction of the platform.
P9 moved them here without rewriting their historical content so the repository
root can remain product-facing.

They are snapshots, not current operating instructions. In particular, old
workstation paths, corpus names, counts, phase statements and relative links are
historical evidence. Use `../../../status.md` for the active state.
