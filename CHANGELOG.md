# Changelog

Notable user-visible and architectural changes are recorded here. Validation transcripts, CI run identifiers and private recovery metadata are intentionally not part of the changelog.

## Unreleased

## 0.3.0 — Product completion

- Expanded the operator console with search, graph, source, durable-job, review, evaluation and health views.
- Hardened vault/path isolation across lexical, semantic, graph, review and evidence boundaries.
- Added real multilingual semantic retrieval with versioned embedding generations and explicit activation/revision consistency.
- Added typed multi-hop graph execution, retrieval planning, ContextPacket continuations and grounded knowledge compilation.
- Improved document-intelligence routing, provider durability, OCR/transcription support and provider endpoint validation.
- Added publication reconciliation for recoverable Git/database failure windows and explicit operator recovery for ambiguous states.
- Added managed-Git backup/restore verification with commit, file and searchable-index checks.
- Added OpenTelemetry traces and metrics across API, worker, backup and restore workflows.
- Added reproducible semantic, document-intelligence, concurrency, resilience, scale and Agent A/B evaluation workflows with bounded claims.
- Productized repository documentation, contributor guidance and hygiene rules so the generic platform no longer depends on a developer workstation, construction artifacts or a specific corpus.

## 0.2.1 — Platform validation

- Updated the supported Node.js runtime and locked Python dependency workflow.
- Hardened authentication, path authorization, idempotency, audit metadata and review publication behavior.
- Added stronger prompt-injection and malicious-content boundaries.
- Expanded multi-vault retrieval, context-packet and lifecycle integration coverage.
- Added deterministic retrieval and scale benchmark harnesses.
- Improved backup/restore isolation and migration verification.
- Tightened repository secret scanning, formatting, contract and runtime validation gates.

## 0.2.0 — Multi-vault knowledge platform

- Introduced the generic vault registry with per-vault membership, visibility and evaluation configuration.
- Added durable event delivery with leases, retries, quarantine, requeue and reconciliation.
- Added incremental lexical, vector, graph and context projection updates.
- Added the provider-neutral document artifact and extraction adapter model.
- Added evaluation packs, retrieval scoring and deterministic offline benchmark infrastructure.
- Added sanitized audit export and separately authorized raw-evidence export.
- Added canonical review/publication and recovery workflows around the managed Git repository.

## 0.1.17 — Knowledge baseline

- Established the local-first Git/PostgreSQL knowledge architecture.
- Added scoped API, CLI and MCP surfaces, deterministic validation and initial retrieval workflows.
- Added migration, backup/restore and dependency-boundary gates.
