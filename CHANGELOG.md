# Changelog

Notable user-visible and architectural changes are recorded here. CI transcripts, local workstation metadata and superseded construction reports are intentionally excluded.

## Unreleased

- Hardened causal event delivery, worker drain semantics and durable retry behavior.
- Added provider-neutral semantic embedding generations with real local multilingual inference support and safe lexical degradation.
- Added typed, scoped and bounded multi-hop graph retrieval with structured path provenance.
- Expanded lexical retrieval, capability-aware planning, rank-fusion provenance and ContextPacket budgeting/profiles.
- Added grounded knowledge compilation against existing approved knowledge with review/governance boundaries and stronger worker fencing.
- Productized repository documentation, evaluation genericity and hygiene rules so maintained product behavior no longer depends on a personal workstation or corpus.

## 0.2.1 — Platform validation

- Updated the supported runtime and reproducible dependency workflow.
- Hardened authentication, path authorization, audit metadata and review/publication behavior.
- Expanded multi-vault retrieval and lifecycle integration coverage.
- Improved backup/restore, migration, secret-scanning, contract and runtime validation gates.

## 0.2.0 — Multi-vault knowledge platform

- Introduced the generic vault registry with per-vault membership, visibility and evaluation configuration.
- Added durable event delivery with leases, retries, quarantine, requeue and reconciliation.
- Added incremental lexical, vector, graph and context projection updates.
- Added provider-neutral document artifacts and extraction adapters.
- Added evaluation packs, retrieval scoring and offline benchmark infrastructure.
- Added canonical review/publication workflows around the managed Git repository.

## 0.1.17 — Knowledge baseline

- Established the local-first Git/PostgreSQL knowledge architecture.
- Added scoped API, CLI and MCP surfaces plus initial retrieval workflows.
- Added migration, backup/restore and dependency-boundary gates.
